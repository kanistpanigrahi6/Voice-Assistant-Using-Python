#Voice Assistant using Python

A simple voice-controlled personal assistant built with Python that can understand voice commands, respond using speech, provide information, open websites, and perform basic computer tasks.

🚀 Features:

🎤 Speech recognition using microphone input
🔊 Text-to-speech responses
🕒 Current date and time
🌐 Opens websites using voice commands
📚 Searches Wikipedia for information
💻 Opens applications and files
🗣️ Voice-based interaction
🤖 Automated responses to user commands


🛠️ Technologies Used
  -Python
  -SpeechRecognition
  -pyttsx3
  -Wikipedia
  -Web Browser
  -Datetime
  -OS Module
